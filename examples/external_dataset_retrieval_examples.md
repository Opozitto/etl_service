# Примеры retrieval по внешнему датасету

Эти примеры демонстрируют source-backed lexical retrieval по внешней документации экологических и инженерных проектов.
Внешние/customer datasets не входят в repo sample corpus и должны храниться вне репозитория; `first_test_data/` оставлен только для маленьких synthetic/generic smoke samples.

ETL service:

- обрабатывает документы разных форматов (DOCX, PDF, XLSX, TXT и др.)
- преобразует их в структурированный JSON (`StructuredDocument`)
- формирует чанки с метаданными и привязкой к источникам
- выполняет лексический поиск evidence-фрагментов для QA-сценариев

Текущий baseline НЕ реализует:

- LLM-генерацию ответов
- semantic/vector search
- embeddings
- полноценный RAG pipeline
- summarization

## Пример 1 — Санитарно-защитная зона

### Вопрос

```text
Какой нормативный размер санитарно-защитной зоны указан для площадки?
```

### Найденный evidence-фрагмент

```text
Для проектируемой площадки нормативный размер санитарно-защитной зоны
составляет 1000 м.
```

### Метаданные retrieval

```text
document: Книга 1 ПЗ.pdf
chunk_type: text
section: Санитарно-защитная зона
match_quality: exact
```

## Пример 3 — Корректировка данных инвентаризации

### Вопрос

```text
Что указано в разделе по корректировке данных инвентаризации?
```

### Найденный evidence-фрагмент

```text
Корректировка данных инвентаризации источников выбросов загрязняющих
веществ выполнена с учетом актуализации технологических показателей.
```

### Метаданные retrieval

```text
document: Приложение 1 Справочные материалы Инвентаризация.docx
chunk_type: text
section: Корректировка данных инвентаризации
match_quality: high
```

## Пример 4 — Retrieval по табличным данным

### Вопрос

```text
Какие загрязняющие вещества указаны в таблице выбросов?
```

### Найденный evidence-фрагмент

```text
Азота диоксид
Азота оксид
Углерода оксид
Сера диоксид
```

### Метаданные retrieval

```text
document: Инвентаризация выбросов.xlsx
chunk_type: table_row
table_context: pollutants
match_quality: high
```

---

## Примечания

- Retrieval-результаты формируются с использованием детерминированного лексического поиска.
- Evidence-фрагменты извлекаются напрямую из индексированных document chunks.
- Метаданные чанков сохраняют информацию об источнике, структуре разделов и табличном контексте.
- Примеры основаны на внешней экологической проектной документации, использованной для оценки и демонстрации работы системы.
